# Parley 1.7.0

## New

- **One-click updates**: from now on, when a new version is out, right-click the tray icon and choose **Update to Parley x.y.z**. Parley downloads it, checks it against GitHub's checksum, installs it and restarts itself, with your settings kept. (This release itself still needs to be installed the usual way.)
- **More WoW versions (beta)**: the addon now also loads on the **Anniversary** realms and **Mists of Pandaria Classic**, besides Classic Era and Retail. Parley installs it into every WoW version it finds. Please [report anything odd](https://github.com/Duhlude/parley/issues).
- **Faster update check**: Parley now looks for new versions right after it opens, then every few hours.

## Download

- **`Parley-Setup.exe`**: the app plus the WoW addon. Installing over an older version keeps your settings.
- **`Parley-addon-1.6.0.zip`**: the addon on its own (1.6.0 adds the Anniversary and Mists of Pandaria Classic versions).
