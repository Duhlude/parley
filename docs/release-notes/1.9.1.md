# Parley 1.9.1

## Changed

- **Parley no longer opens the WoW process at all.** It now finds the WoW window through Windows' list of running programs. (Before, it briefly opened the process with the most limited access Windows has, only to read the program's name.) The app still never reads game memory, injects anything or sends input; it only reads the few pixels the addon draws on screen.
- **Clearer, more honest docs.** The README, User Guide and "How it works" now describe exactly what the app touches, and quote the part of Blizzard's EULA about software that collects information from the game. Parley has not been reviewed or approved by Blizzard; please read "Is this safe?" in the User Guide.

## Updating

Right-click the tray icon and choose **Update to Parley 1.9.1**, or download **`Parley-Setup.exe`** below. Your settings are kept. The WoW addon is unchanged (still 1.6.0).
