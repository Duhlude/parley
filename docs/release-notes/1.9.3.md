# Parley 1.9.3

## New

- **WoW: Forever beta (beta support)**: the addon now loads in the Forever beta, and Parley installs it into the beta's `_classic_beta_` folder automatically. Forever uses Retail's addon rules, so like on Retail, Blizzard may hide chat from addons in some situations; Parley says so in the overlay and picks up again afterwards.
- Parley now recognises new WoW builds by their game window, even if the game program has a new name.

## Updating

Right-click the tray icon and choose **Update to Parley 1.9.3**, or download **`Parley-Setup.exe`** below. Type `/reload` in WoW afterwards.

- **`Parley-addon-1.6.2.zip`**: the addon on its own.
